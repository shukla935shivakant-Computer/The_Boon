# Boon Android App - Pre-built APK

This folder contains the pre-compiled Android APK ready for testing and installation on Android devices.

- **File:** `apk/app-debug.apk` (Size: ~23MB)
- **Application ID:** `com.aistudio.boon.vktpx`
- **Minimum Android Version:** Android 7.0 (API 24)
- **Target Android Version:** Android 15 (API 36)

### How to Install on Android
1. Download `apk/app-debug.apk` to your Android device.
2. Open the file and allow **"Install unknown apps"** if prompted by Android.
3. Tap **Install** and open **Boon**.
